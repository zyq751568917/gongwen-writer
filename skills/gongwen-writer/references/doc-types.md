# 15 种法定文种的结构模板

依据：中办发〔2012〕14号《党政机关公文处理工作条例》（2012-07-01 印发）。该条例第八条列明 15 种法定公文种类：决议、决定、命令、公报、公告、通告、意见、通知、通报、报告、请示、批复、议案、函、纪要。

## 1. 行文方向与文种对照

| 方向 | 文种 | 说明 |
|---|---|---|
| 上行文 | 报告、请示、议案 | 需签发人；请示必须一文一事、只写一个主送机关 |
| 平行文 | 函、通知（部分）、纪要 | 函用于不相隶属机关之间商洽工作、询问答复问题、请求批准和答复审批事项 |
| 下行文 | 命令、决定、公告、通告、通知、意见、批复、通报 | 批复是被批文件的下行文 |

## 2. 各文种结构骨架

### 决议 / 决定
标题 → 主送机关 → 正文（形势与依据、决定事项、执行要求）→ 落款与日期。
特点：决定可分条列项，层次用"一、二、"；正文写清依据（法律法规、上级决定）与执行要求。

### 命令
标题（××部令 第×号）→ 主送机关 → 正文（发布令、施行日期）→ 落款、日期、印章。
特点：正文短，结尾为"特令"或"此令"。

### 公报
标题 → 正文（会议基本情况、主要议程与决定）→ 落款、日期。用于报道重要会议或重要决定事项。

### 公告
标题 → 正文（公布事项、法律效力和施行时间）→ 落款、日期。
特点：内容简短，一般不超过千字；不设主送机关；使用法定计量单位；不用"兹"字。

### 通告
标题 → 主送机关 → 正文（公布应当遵守或周知的事项）→ 落款、日期。
与公告区别：公告向国内外宣布重要事项，通告在一定范围内公布应当遵守或周知的事项。

### 意见
标题 → 主送机关 → 正文（指导思想/总体要求 → 主要任务 → 保障措施）。
分条用"一、（一）1. （1）"；每部分标题用黑体/楷体分层次。

### 通知
标题 → 主送机关 → 正文（告知事项、要求事项、执行时间与要求）→ 落款、日期。
结尾常用"请遵照执行""特此通知""请予支持""望遵照执行"。

### 通报
标题 → 主送机关 → 正文（情况概述、原因分析、奖惩或工作要求）→ 落款、日期。
分条一般不超过 4 条。

### 报告
标题 → 主送机关 → 正文（基本情况、做法成效、问题分析、下一步打算）→ 落款、日期。
结尾常用"特此报告"；不得夹带请示事项；工作报告常用"现将有关情况报告如下"。

### 请示
标题 → 主送机关 → 正文（请示缘由、请示事项、简短的请求）→ 落款、日期。
一文一事；只写一个主送机关；结尾常用"妥否，请批示""当否，请批复"；不得越级。

### 批复
标题 → 主送机关 → 正文（引用来文标题与发文字号、答复意见）→ 落款、日期。
标题写明被批文件的标题和发文字号。

### 议案
标题 → 主送机关（人民代表大会或常务委员会）→ 正文（提请审议事项、说明）→ 落款、日期。

### 函
标题 → 主送机关 → 正文（商洽事项、请求或答复事项）→ 落款、日期。
分商洽函、询问函、答复函、请批函、告知函；结尾常用"请予支持""此复""专此函达"。

### 纪要
标题 → 正文（会议基本情况、会议议定事项）→ 落款、日期。
用"一、"分条写议定事项；不加盖印章；发至与会人员。

## 3. 要素自检清单（写完对照）

- [ ] 文种是否与行文方向匹配（请示一文一事、不夹带报告事项）
- [ ] 标题是否"关于××的＋文种"，发文机关 + 事由 + 文种三要素齐全
- [ ] 主送机关是否准确、是否全角冒号、是否顶格
- [ ] 是否只有附件说明（不出现"附件："后又写"附件："）
- [ ] 成文日期是否用阿拉伯数字、右空 4 字、在署名之上
- [ ] 层次序数是否一、（一）1.（1）且字体依次为黑体、楷体、仿宋
- [ ] 文种专属收尾语是否用对
