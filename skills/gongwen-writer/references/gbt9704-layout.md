# 公文版式要素（GB/T 9704-2012《党政机关公文格式》）

依据来源：
- 国家标准 GB/T 9704-2012《党政机关公文格式》（2012-06-29 发布，2012-07-01 实施）
- 中办发〔2012〕14号《党政机关公文处理工作条例》
- 用户提供的《加快公文运转提高工作效率的通知》附件（无标号版式说明稿），本文件中标注为"附件说明稿"

条款号沿用国标编号；凡本文件给出"附件说明稿"标注的，为该说明稿的页边标注，未标注的取国标通行做法。

## 1. 页面与版心（国标 5.2 / 附件说明稿 5.2.1、5.2.3）

| 项 | 规格 |
|---|---|
| 用纸 | A4，210mm × 297mm |
| 天头（上白边） | 37mm（±1mm） |
| 订口（左白边） | 28mm（±1mm） |
| 版心 | 156mm × 225mm |
| 推得边距 | 上 37mm、下 35mm、左 28mm、右 26mm |
| 每面行数 | 22 行（附件说明稿 5.2.3） |
| 每行字数 | 28 字（附件说明稿 5.2.3） |
| 正文颜色 | 黑色（附件说明稿 5.2.4） |

## 2. 版头（国标 7.2）

顺序：发文机关标志 → 红色分隔线 → 发文字号 → 签发人（上行文）。

- **发文机关标志**（7.2.4）：居中排布，上边缘至版心上边缘 35mm；字体用小标宋体，红色，字号由上级机关确定。
- **发文字号**（7.2.5）：编排在发文机关标志下空二行位置，3 号仿宋体。
  - 平行文、下行文：居中编排。
  - 上行文：发文字号居左空 1 字，签发人居右空 1 字。
  - 年份用六角括号〔〕括入，不得使用方括号 [] 或圆括号（）——依据中办发〔2012〕14号与国标式样。
- **签发人**（7.2.6）：仅上行文标注。"签发人"三字用 3 号仿宋体，冒号后签发人姓名用 3 号楷体；右空 1 字。多个签发人从左到右、自上而下依次均匀编排，一般每行两个，回行与上一行第一个姓名对齐。
- **红色分隔线**：与版心等宽的红色横线，位于发文字号/签发人之下。

## 3. 主体（国标 7.3）

| 要素 | 规格 |
|---|---|
| 标题（7.3.1） | 2 号小标宋体字，编排在红色分隔线下空二行位置；回行时词意完整、排列对称、长短适宜、间距恰当，排列呈梯形或菱形 |
| 主送机关（7.3.2） | 标题下空一行位置，居左顶格，名称后用全角冒号 |
| 正文（7.3.3） | 3 号仿宋体；公文首页必须显示正文 |
| 层次序数（7.3.3） | 第一层"一、二、"用 3 号黑体；第二层"（一）（二）"用 3 号楷体；第三层"1. 2."、第四层"（1）（2）"用 3 号仿宋体 |
| 附件说明（7.3.4） | 正文下空一行（左空 2 字符），附件名称后不加标点；多个附件用阿拉伯数字标注顺序号；名称长时回行与冒号后文字对齐 |
| 发文机关署名（7.3.5） | 在成文日期之上；单一机关制发公文必须署发文机关全称或规范化简称（中办发〔2012〕14号第九条第十一项） |
| 成文日期（7.3.5） | 在发文机关署名之上，署名与正文（或附件）之间约空三行；用阿拉伯数字；右空 4 字 |
| 印章（7.3.5） | 红色，端正中下压发文机关署名和成文日期；印章顶端上距正文（或附件说明）一行之内 |
| 附注（7.3.6） | 成文日期下空一行，左空 2 字符加圆括号编排 |
| 附件（7.3.7） | "附件"标识在左上角第一行顶格，3 号黑体，标识与附件名称中间空一行；附件标题居中编排在版心第三行；附件格式要求同正文；附件顺序号与附件标题应与附件说明一致 |

## 4. 版记（国标 7.4）

- **抄送机关**（7.4.2）：4 号仿宋体，编排在印发机关和印发日期之上，左右各空 1 字符；抄送机关间用逗号分隔，最后一个抄送机关名称后标句号；回行时与冒号后首字对齐。
- **分隔线**（7.4.1）：版记中的分隔线与版心等宽；首条分隔线和末条分隔线用粗线（推荐高度 0.35mm），中间的分隔线用细线（推荐高度 0.25mm）；首条位于版记第一个要素之上，末条与公文最后一面的版心下边缘重合。
- **印发机关和印发日期**（7.4.3）：一般用 4 号仿宋体；印发机关左空 1 字符，印发日期右空 1 字符；用阿拉伯数字标全年月日，不编虚位，后加"印发"二字。

## 5. 页码（国标 7.5）

- 4 号半角宋体阿拉伯数字，数字左右各放一条一字线。
- 单页码居右空 1 字，双页码居左空 1 字。
- 公文的附件与正文一起装订时，页码连续编排。

## 6. 主题词

GB/T 9704-2012 前言已删除主题词格式要素，不再编排主题词（附件说明稿亦有此说明）。

## 7. 已知与国标不同的单位惯例

- 发文字号的机关代字与序号规则以本单位发文登记为准，本技能默认国标式样（机关代字〔年份〕序号），实际编号在确认单中由用户拍板。
- 红头字号、红头是否带"文件"二字、是否使用标识与文种分离的版式，由用户确认单决定，spec.json 支持逐项覆盖。
