# 依据检索与引用规则

需求来源：公文结构与文体存疑时，需要参考官媒或政府官网发布的正式公文范例，并在回答中给出可核对的依据。

## 1. 来源优先级

1. **国标与党内法规原文**：GB/T 9704-2012《党政机关公文格式》、中办发〔2012〕14号《党政机关公文处理工作条例》。
2. **政府官网与官媒正式发布的公文范例**：中国政府网（gov.cn）、国务院公报、各级人民政府门户网站的"公文""政府文件"栏目、《人民日报》《光明日报》等党报要闻版。
3. **其他权威机关公开范例**：党校、人大、政协、政府部门官网。

**排除**：自媒体、论坛、公众号转载、文库站点、问答社区、模板下载站、百科类词条。

## 2. 检索式模板

- `site:gov.cn 关于××的请示`
- `site:gov.cn 关于××的通知 全文 国务院办公厅`
- `××人民政府办公室 关于××的通知 发文字号`
- `国务院公报 关于××的批复`
- 结构存疑时：`site:gov.cn 会议纪要 议定事项 格式`

## 3. 引用格式

- 结论后紧跟依据，例："正文层次序数依次使用一、（一）1.（1）〔依据 GB/T 9704-2012 第7.3.3条〕"。
- 引用网络范例时给可点链接，例："参考中国政府网《××市人民政府关于××的通知》（https://www.gov.cn/...）"。
- 交付说明里单列"依据来源"清单，逐条写来源名 + URL + 引用了什么。

## 4. 硬约束

- **不得编造条款号**：不确定条款号时只写"依据 GB/T 9704-2012"并说明具体章节，不猜数字。
- **不得虚构 URL**：只引用实际打开过的页面。
- **检索不到就如实说**："未检索到官方发布范例，以下按 GB/T 9704-2012 通用要求处理。" 不硬凑依据。
- 检索结果只作参照，**不得直接搬运他人公文正文**，只借鉴结构与用语。

## 5. 什么时候必须查

- 不确定的文种结构或要素顺序。
- 拿不准的文种收尾语或请求语。
- 需要与上级最新文件对标的表述。
- 用户明确要求"参考官方范例"。

其余情况直接用本技能内置的国标条款与模板，不必联网。
