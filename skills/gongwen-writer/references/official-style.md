# 公文语言与文体规范

适用范围：党政机关公文的正文语言。本文件是**通用公文规范**，不含任何单位或个人写作偏好。

## 1. 语体

- 书面、庄重平实、简明准确。以陈述句、判断句为主。
- 不用口语、俚语、网络用语、表情符号；不用感叹号、反问句渲染情绪。
- 不写"我们觉得""非常""特别""搞""弄""一下子"等口语词。
- 少用第一人称"我们"（除集体署名行文），主语用机关或集体。

## 2. 结构

- 总—分：先给结论或总体要求，再分条说明。
- 一级标题（"一、"）是完整判断句，概括本部分主旨，不写成"基本情况""相关工作"这类空标签。
- 不设只有形式没有内容的段落（如"意义重大""影响深远"）。
- 分条不超过 4 条为宜；条目之间不重复。

## 3. 用词

- 沿用法律法规、行业规范与本单位既有表述，不自造术语。
- 同一概念全文统一用词，不换说法。
- 避免英文缩写（法规名、专有名词、机构简称除外）。
- 数字用法：公历世纪、年代、年月日、时刻、计数与计量一律阿拉伯数字；概数用"几""十"；概数与准确数连用时用约数。
- 时间表达："截至11月25日""2026年第三季度"，不用"截止到"。

## 4. 标点

- 中文全角标点：，。；：？！“”（）《》、……——
- 年份六角括号〔〕，不用 [] 或 ()
- 顿号、逗号层次：并列用"，"或"、"，分句用"。"
- 破折号用两个"—"，省略号用"……"

## 5. 风格微调（可选；决定前必须先向用户说明）

"去 AI 味"一类的风格处理属于**用户个人取向**，不是公文规范要求。本技能**不默认执行**，也不擅自删改用户已有的表述。

可选的处理方式（说明时用来举例，不是强制清单）：

- 精简整齐排比与四字格堆砌（"层层传导""持续夯实""筑牢底线""赋能增效"）。
- 精简宣传腔副词连用（切实、坚决、扎实、全面、深入）。
- 打散同构句式：每段都以"一是……二是……三是……"开头、每段都收在总结句。
- 用具体事实替代抽象名词：写清楚"哪台设备、哪个环节、什么时候、谁负责"。
- 删掉没有实指的名词化短语（"工作闭环""机制保障""效能提升"）。

执行规则：

1. **决定前先给用户说明**：说明准备做哪几类处理、大致会动到哪些段落、给一两句前后对照，让用户判断值不值得改；不要只丢一句"要不要精简"就动手。
2. 说明完由用户拍板：采用哪几类、到什么程度（整体精简 / 只改明显空话 / 完全保持原样）。
3. 用户没有表态就保持原样，不替他做主；用户选了才动，且改动逐条列出来给他看。

## 6. 常用句式

- 目的句："为××，根据××，现将有关事项报告如下。"
- 依据句："根据《××》（××〔2026〕×号）的要求，……"
- 事实句："截至11月25日，已完成××，处理××起。"
- 责任句："由××牵头，××配合，于×月×日前完成。"
- 请示句："妥否，请批示。"
- 报告句："特此报告。"
- 通知句："请遵照执行。"

## 7. 写完自检

- [ ] 有没有一句是删掉也不影响事实的空话？（属第 5 节的可选处理：用户同意精简才删）
- [ ] 层次标题是否都能单独读懂？
- [ ] 事实、依据、要求、责任、时间是否齐全？
- [ ] 有没有把个人偏好或未经核实的数字写进去？
- [ ] 标点是否全为中文全角？数字与西文是否用 Times New Roman？
